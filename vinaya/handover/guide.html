2. Before you start

You need a GoDaddy Web Hosting (cPanel, Linux) plan and your domain. The website needs:

  • PHP 8.1 or newer. The enquiry form and the admin panel run on PHP.
  • SSL (https). GoDaddy cPanel plans include free SSL.
  • About 10 MB of space.
Website Builder plans will not work. They do not accept uploaded websites. If unsure, check that your GoDaddy hosting shows cPanel Admin.

3. Upload the website to GoDaddy

  1. Log in to GoDaddy and go to My Products → Web Hosting → Manage → cPanel Admin.
  2. Open File Manager and go into the public_html folder. If it contains a GoDaddy placeholder page (for example index.html or default.html), delete it.
  3. Click Upload and upload Vinaya-Website-Files.zip into public_html.
  4. Back in File Manager, right-click the zip and choose Extract. Extract into /public_html and allow it to replace files.
  5. Delete the zip file afterwards.
  6. Check: public_html should now contain index.html, contact.php and the folders admin, assets, images, blog, products and others. The files are directly inside public_html, not in a sub-folder.
Some files start with a dot (.htaccess). They are hidden by default. In File Manager, Settings → Show Hidden Files lets you see them. They must stay; they make the site fast and protect the admin data.

Set the PHP version

In cPanel, open Select PHP Version (or MultiPHP Manager) and choose PHP 8.1 or newer for your domain.

4. Connect the domain and switch on https

  1. If the domain is with GoDaddy and attached to this hosting plan, it already points to the website.
  2. If the domain is elsewhere, point its A record to the IP address shown in cPanel (right-hand panel, "Shared IP Address"). Changes can take a few hours.
  3. In cPanel, open SSL/TLS Status and run AutoSSL so the site works on https://.
  4. Open your domain in a browser: the Vinaya home page should appear.

5. First login and setup (10 minutes)

  1. Go to https://yourdomain.com/admin/ and log in with username vinaya and the password sent separately.
  2. Account tab: change the password to one only you know (at least 10 characters).
  3. Contact details tab, fill in:
    • Website address: your domain, for example https://www.yourdomain.com
    • Enquiry emails go to: the inbox that should receive enquiries. The form goes live once this is set.
    • Email shown on the website and WhatsApp number (country code, digits only, e.g. 919876543210)
    • Send form emails from: an address on your own domain, e.g. noreply@yourdomain.com (create it in cPanel → Email Accounts). This helps enquiries arrive and not land in spam.
    • Instagram, YouTube and X links are already filled in. Change or clear them if needed.
  4. Press Publish. The whole website updates in a few seconds.
  5. Test: open the Contact page, send yourself an enquiry, and check it arrives (also check spam).

6. Updating the website yourself

Everything is done at /admin/. Changes are saved safely and go live when you press Publish (photos, products and blog posts publish as soon as you save them).

TabWhat you can do
TextEdit every line on the website, grouped page by page, with a search box. Changed lines are highlighted and can be undone. Put words between *stars* to show them in the green accent style.
ProductsAdd a new product (name, subtitle, category, photo, description, short tags, details). Edit or delete products you added. Hide any product to take it off the site without deleting it. Each product gets its own page, a card on the Products page and a place in the enquiry form.
BlogWrite new articles with a toolbar for headings, bold, italics, bullet and numbered lists, quotes, links and photos inside the article. Set a cover photo, category, date and a "featured" post. Edit or delete any article.
PhotosEvery photo on the site is listed with where it appears and its best size. Replace photo takes a picture from your phone or computer; it is resized automatically and the site crops it to fit.
Contact detailsWebsite address, enquiry email, public email, WhatsApp and social links.
AccountChange your password.

Photo tips

  • Use bright, natural-light photos. Landscape for banners and blog covers, portrait for cards and products.
  • Where text sits on a photo (banners, the Home cards), keep that part of the photo calm.
  • Only use photos you own or have permission to use.
  • A full list of photo sizes is at https://yourdomain.com/images/guide.html.

7. Safety and backups

  • Your edits, uploaded photos and password are stored in a folder called vinaya-data, next to public_html (one level above it). It is not visible on the web.
  • Back up both public_html and vinaya-data from time to time (cPanel → Backup, or download them from File Manager).
  • If the website files are ever uploaded again, your edits are not lost: log in to the admin once and they are re-applied automatically.
  • After 5 wrong passwords the admin locks for 15 minutes. You are logged out automatically after 2 hours of inactivity.
