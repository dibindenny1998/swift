# Images

Drop photos here with these names (.webp, .jpg or .png) and run `node build.mjs`.
Until a file exists, the site shows a labelled placeholder box in its place.

| File | Where it appears | Frame |
|---|---|---|
| `home-hero` | Home, beside the slogan | portrait 4:5 |
| `story-hero` | Our Story, top | wide 16:9 |
| `story-garden` | Our Story, image pair (left) | portrait 4:5 |
| `story-hands` | Our Story, image pair (right) | landscape 3:2 |
| `export-hero` | Partner With Us, top | landscape 3:2 |
| `products/hair-oil` | Hair Oil card, product page, Home "Featured" | portrait 4:5 |
| `products/gift-set` | Gift Set card, product page, Home "Gift Set" | portrait 4:5 |
| `og-image.jpg` | Social media share preview (1200 × 630) | already provided |

Slots are defined in `content/images.mjs`; alt text is in `content/en.json` under `images`.
This README is not copied into the website.
