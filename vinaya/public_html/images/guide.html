Vinaya · Image guide

Every picture on the website is a file in this folder (public_html/images/). To change one, upload a new file with the same name in Hostinger File Manager and overwrite the old one.

Any size works: the site crops to the frame automatically. The labels below compare each current file with its recommended size. Keep files under 400 KB for a fast site.
